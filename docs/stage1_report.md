# Отчёт по первому этапу «Поле»

Документ ведётся по ходу работы. Спорные решения — в [open_issues.md](open_issues.md).

## Как собрать и проверить
- JDK 17, Gradle 8.1.1 (wrapper в репозитории), ForgeGradle 6, Forge 47.3.0, official mappings.
- `./gradlew build` — сборка и юнит-тесты; `./gradlew test` — только тесты.
- `./gradlew runServer` — выделенный сервер без необязательных модов; с ними — `./gradlew runServer -Pwith_optional=true`.

## Ход работы

### Ядро (чистая логика, без Minecraft)
Пакет `faygolover.rpmedicine.core`: части тела, раны, осложнения, физиология, заживление, лечение, осмотр, последствия в игре. Все числа — в `MedicalSettings` (заполняется из серверного конфига). Покрыто юнит-тестами (`src/test/java`).

Проверено тестами:
- артериальное кровотечение без помощи — потеря сознания через ~4 минуты; жгут на ноге перекрывает и стопу;
- нокдаун длится 3–5 минут и при остановке сердца, и при кровопотере; устранение причины останавливает таймер, пробуждение за 20–60 с;
- болевой шок через 20–30 с — обморок без таймера; обезболивание будит;
- открытый пневмоторакс переходит в напряжённый, напряжённый останавливает сердце; наклейка останавливает развитие, игла снимает напряжённый;
- восстановление крови 500 мл/ч, физраствор не больше трети объёма;
- клиническая смерть в режиме «без смерти», реанимация СЛР с адреналином, последствия после неё; без режима — смерть;
- тяжесть = урон × 5, слияние ран, не больше 6 записей, рост шанса осложнений с тяжестью;
- место попадания по высоте и стороне, падение, взрыв;
- заживление по времени, пуля внутри не даёт заживать, перелом заживает только с шиной;
- проверка «лечение нужно», выбор части при быстром применении, ошибка медика, навык;
- детализация осмотра по уровню, себя — не выше уровня 1;
- хромота, только ползком при двух сломанных ногах, обезболивание снимает ограничения перелома, обе сломанные руки.
